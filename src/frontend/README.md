# ⚛️ Frontend Web App — Wellness Platform (React + Vite)

Este directorio contiene la aplicación web de una sola página (SPA) construida con **React 18**, **Vite** y **CSS Vainilla (Emil Kowalski Design System)**.

---

## 🎨 Características de Diseño (UI/UX)

- **Diseño Adaptable (Mobile-First)**: Navegación inferior tipo *Bottom Sheet* para dispositivos móviles y barra lateral ergonómica para escritorio.
- **Glassmorphic Aesthetic**: Fondos difuminados con `backdrop-filter: blur(16px)` y sombras con resplandor neón.
- **Animaciones de Resorte**: Transiciones suaves en modales (`slideUp`) y micro-interacciones táctiles.

---

## ⚙️ Comandos de Desarrollo y Compilación

```bash
# 1. Instalar dependencias
npm install

# 2. Iniciar servidor local
npm run dev

# 3. Compilar para producción
npm run build
```
