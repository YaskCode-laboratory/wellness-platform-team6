# Changelog — Wellness Platform

Todas las mejoras y cambios significativos en este proyecto serán documentados en este archivo.

## [1.0.0] - 2026-08-09
### Agregado
- Integración completa del frontend React Vite y el backend FastAPI.
- Estructuración del proyecto en la arquitectura recomendada por la maestría TIC (`src/backend`, `src/frontend`, `docs/`, `docker/`, `prompts/`, `data/`, `scripts/`, `tests/`, `assets/`, `.github/`).
- Despliegue en producción en AWS EC2 (Backend) y AWS Amplify (Frontend).
- Documentación exhaustiva en archivos `README.md` en cada módulo.
- Pruebas automatizadas de Ficha Técnica, reasignación de entrenadores y alta de personal.
